# Public assets and reference data

Vite copies this directory into the built frontend. It contains the app icon and local geographic/reference assets under `data/`.

- `data/geoaccess/` includes derived geographic context, modeled population and fictional facility examples used by GEOACCESS.
- Other local GeoJSON files support the overview and synthetic examples.
- [Data and imagery attribution](data/ATTRIBUTION.md) describes sources, licences and limitations. Third-party imagery may have non-commercial terms.

Geographic boundaries and modeled population are published reference inputs, not verified healthcare records. Facility examples, healthcare indicators and referrals are fictional. Do not add real patient information, credentials or sensitive files to this public directory.

# Application source

The React and TypeScript frontend for the synthetic senTRA prototype lives here.

| Path | Purpose |
| --- | --- |
| `geoaccess/` | Geographic exploration, map controls and synthetic facility scenarios. |
| `reflex/` | Local synthetic referral, matching, tracking and analytics demonstrations. |
| `mamaguard/` | Fictional maternal and newborn coordination workflows. |
| `platform/` | Workspace previews and the synthetic account-service client. |
| `components/`, `pages/`, `hooks/` | Shared navigation, maps, pages and UI state. |
| `data/`, `engines/`, `services/`, `types/` | Demo data, calculations, service boundaries and shared types. |

The account API is separate from the other demonstration workspaces. No real patient or professional information belongs here. See the [project overview](../README.md) and [technical reference](../docs/PROJECT-REFERENCE.md).

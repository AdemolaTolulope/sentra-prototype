# Geographic data attribution

- `nigeria-adm1.geojson`: NGA ADM1 simplified boundaries from GRID3 via [geoBoundaries](https://www.geoboundaries.org/), 2022 representative year, built 12 December 2023, CC BY 4.0 according to the accompanying `metadata.txt`. Geometry is retained, while display names, representative label points and synthetic access-score properties have been added. The FCT display name has been expanded to include Abuja. See the project README for the full citation and source URL.
- `nigeria-outline.geojson`: dissolved from the ADM1 polygons above; same attribution applies.
- `west-africa-context.geojson`: selected neighbouring countries from Natural Earth 1:110m Admin 0, public domain. These are small-scale contextual shapes, not verified local boundaries.
- `demo-markers.geojson`: randomly generated fictional points within the ADM1 polygons. These are **not real facilities or settlements**.

## Optional satellite imagery and globe

- Global demonstration satellite: EOxCloudless [https://cloudless.eox.at](https://cloudless.eox.at/) by [EOX IT Services GmbH](https://eox.at/) (Contains modified Copernicus Sentinel data 2024), served from the `s2cloudless-2024_3857` WMTS. [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/); the hosted demonstration service is non-commercial without an appropriate commercial licence. The mosaic is historical and approximately 10 m per pixel; enlarged tiles do not become building-level imagery. See [EOX licence and service terms](https://cloudless.eox.at/documentation/license).
- Detailed demonstration scenes: [OpenAerialMap](https://imagery.hotosm.org/) STAC catalogue and per-item raster service. The map accepts only `CC-BY-4.0` and `CC-BY-NC-4.0` items with a named producer and title, and displays each displayed catalogue match’s producer, title, acquisition date when supplied, nominal ground-sample distance, licence and item link. Coverage is uneven and catalogue bounding-box intersection does not guarantee imagery at a particular pixel. For example, the Lagos scene tested was **Maxar 2019 Lagos Mosaic**, Maxar, acquired 5 June 2019, ~0.5 m/pixel, [CC BY-NC 4.0](https://creativecommons.org/licenses/by-nc/4.0/), via [OpenAerialMap](https://api.imagery.hotosm.org/browser/stac/collections/openaerialmap/items/5ea1cb44411bed00056803b8). This is not a national coverage estimate. Non-commercial scenes cannot be used commercially without the relevant permission.
- Optional MapTiler satellite is used only when an operator supplies their own browser key. [© MapTiler and its imagery providers](https://www.maptiler.com/copyright/); the source TileJSON attribution and the MapTiler logo are displayed. The operator is responsible for the applicable licence, domain restrictions, plan, pricing and data coverage. No key is supplied. A real account connection was not tested; the UI and failure/recovery paths were tested with mocked responses.
- Imagery, catalogue and logo requests are optional and not cached by the senTRA service worker. Their providers receive the viewer's IP address and requested geographic viewport; browser HTTP caches are separate. **Use local map only** pauses these and other optional geography sources when browser storage and app state permit. Imagery is not live; terrain and simple, approximate OSM building extrusions do not create photorealistic 3D.

## Optional geographic context (Stage 4.5)

- Vector map tiles and mapped healthcare points: [OpenStreetMap contributors](https://www.openstreetmap.org/copyright), ODbL 1.0, served as OpenMapTiles-format data by [OpenFreeMap](https://openfreemap.org/). Map design uses custom senTRA layers. Coverage, age and completeness vary; roads do not establish passability or routing. Mapped healthcare POIs are **unverified**, not a facility registry, not linked to the fictional senTRA facility IDs and not included in calculations. The public service is as-is and may be unavailable.
- Buildings: OpenStreetMap footprints via OpenMapTiles. `render_height` is approximate and may come from level estimates. A 5 m value can be Planetiler's default for unknown height, so those footprints remain flat (including genuine 5 m features that cannot be distinguished). No height is represented as a survey measurement.
- Elevation: [Mapzen Terrain Tiles on AWS Open Data](https://registry.opendata.aws/terrain-tiles/) (Terrarium DEM); source-dependent credits include USGS SRTM/GMTED2010 and NOAA, as described in [Tilezen source attribution](https://github.com/tilezen/joerd/blob/master/docs/attribution.md). This is a mixed-vintage, bare-earth model and not surveyed local infrastructure.
- These public services are optional and not precached by senTRA. The viewer's IP address and map viewport are exposed to the providers when enabled. No referral or patient records are sent. Use “local map only” to stop optional map use; already requested data may remain in the browser cache.

# Security and responsible disclosure

senTRA is a synthetic demonstration, not a production healthcare system. Do not enter real patient/professional information or connect real users. The identity provider, mailbox and professional-verification services are not configured by default; other workspaces are separate demonstrations and are not protected by the synthetic identity API.

## Report a concern

Please **do not post credentials, personal information or exploitable vulnerability details in a public issue**. If GitHub's private vulnerability reporting is enabled for this repository, use the **Security** tab and choose **Report a vulnerability**. Otherwise, contact the repository owner privately before sharing details. Private reporting availability and response times have not been established.

Only test systems for which you have explicit authorization. Do not send real health information, access other people's accounts, or probe external providers as part of this project. Include only enough synthetic, non-secret detail to reproduce a concern.

The [security and data map](docs/MILESTONE-1-SECURITY-AND-DATA-MAP.md) documents the current trust boundaries and known gaps. Security review, protected shared storage, independent audit, abuse controls and clinical governance remain outstanding before any real-data pilot.
